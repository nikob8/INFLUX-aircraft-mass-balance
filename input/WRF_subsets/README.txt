WRF-Chem subsets (not part of this repository)
==============================================

analyses/Diagnostic_ratio.m reads the files WRF_subset_<yyyymmdd>.mat from this
folder.  The 37 files (4.0 GB in total) are archived as a separate Zenodo data
set, https://doi.org/10.5281/zenodo.24184894; wrf/WRF_subsets_README.txt
describes their content.
